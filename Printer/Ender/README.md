# Ender 3 Pro

A Creality Ender 3 Pro converted to Klipper, run from a Raspberry Pi (`ender.local`) with a web interface.

The full step-by-step is in [klipper-ender3-guide.md](klipper-ender3-guide.md): flashing the firmware, setting up the Pi and Wi-Fi, installing Klipper and the web interface, updating, printing from the Pi, and the problems we hit along the way with their fixes.

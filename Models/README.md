# Models

One folder per model. Each has a `NOTES.md` with the decisions and history, and, where the model is generated, a `build.sh` that rebuilds it from scratch.

| Model | What it is |
|-------|------------|
| [Engine/](Engine/) | A 15 cm printable car engine with a motor-driven flywheel and fan, and a smoke system blowing through the exhaust |

Build outputs (`output/`), intermediates (`work/`) and downloaded source models (`source/`) are not committed. Run the model's `build.sh` to regenerate them.
